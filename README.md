# Portfolio + TaskFlow (UI) 🌿

A warm, interactive portfolio website featuring **Soft UI design**, **scroll-triggered animations**, and an embedded **TaskFlow task manager** built with **Vanilla JavaScript**.

## 🌐 Live Demo ![click-here](https://github.com/user-attachments/assets/221e4334-094a-43da-bae3-96ee05bedbfd)

https://decentketan01.github.io/taskflow-portfolio/#projects

---

## ✨ Highlights

### 🎨 UI/UX
- Warm palette (cream / terracotta / sage)
- Rounded components (24px+)
- Layered depth shadows and airy spacing

### 🫧 Interactive Background
- **Layered SVG morphing blobs**
- Animated gradient transitions
- Subtle parallax depth on mouse movement

### ⚡ Micro-Interactions
- Smooth custom cursor
- Magnetic CTA button effect
- Soundless “haptic” press feedback
- Scroll reveal animations (IntersectionObserver)

### ✅ TaskFlow App Demo (Vanilla JS)
- Add / delete / complete tasks
- Filters (All / Done / Pending)
- Persistent storage using localStorage

---

## 🛠 Tech Stack
- HTML5
- CSS3 (Grid/Flexbox + Soft UI system)
- Vanilla JavaScript (ES6)
- SVG Morph + Gradients (SMIL animations)
